# List of Wrappers

Gymnasium provides a number of commonly used wrappers listed below. More information can be found on the particular
wrapper in the page on the wrapper type

| Name                                                                                        | Description                                                                                                                                                                                                                  |
|---------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [`AddRenderObservation`](observation_wrappers.md#gymnasium.wrappers.AddRenderObservation)   | Includes the rendered observations in the environment’s observations.                                                                                                                                                        |
| [`AddWhiteNoise`](misc_wrappers.md#gymnasium.wrappers.AddWhiteNoise)                        | Randomly replaces pixels with white noise.                                                                                                                                                                                   |
| [`ArrayConversion`](misc_wrappers.md#gymnasium.wrappers.ArrayConversion)                    | Wraps an Array API compatible environment so that it can be interacted with another Array API framework.                                                                                                                     |
| [`AtariPreprocessing`](misc_wrappers.md#gymnasium.wrappers.AtariPreprocessing)              | Implements the common preprocessing techniques for Atari environments (excluding frame stacking).                                                                                                                            |
| [`Autoreset`](misc_wrappers.md#gymnasium.wrappers.Autoreset)                                | The wrapped environment is automatically reset when a terminated or truncated state is reached.                                                                                                                              |
| [`ClipAction`](action_wrappers.md#gymnasium.wrappers.ClipAction)                            | Clips the `action` pass to `step` to be within the environment’s action_space.                                                                                                                                               |
| [`ClipReward`](reward_wrappers.md#gymnasium.wrappers.ClipReward)                            | Clips the rewards for an environment between an upper and lower bound.                                                                                                                                                       |
| [`DelayObservation`](observation_wrappers.md#gymnasium.wrappers.DelayObservation)           | Adds a delay to the returned observation from the environment.                                                                                                                                                               |
| [`DiscretizeAction`](action_wrappers.md#gymnasium.wrappers.DiscretizeAction)                | Uniformly discretizes a continuous Box action space into a single Discrete space.                                                                                                                                            |
| [`DiscretizeObservation`](observation_wrappers.md#gymnasium.wrappers.DiscretizeObservation) | Uniformly discretizes a continuous Box observation space into a single Discrete space.                                                                                                                                       |
| [`DtypeObservation`](observation_wrappers.md#gymnasium.wrappers.DtypeObservation)           | Modifies the dtype of an observation array to a specified dtype.                                                                                                                                                             |
| [`FilterObservation`](observation_wrappers.md#gymnasium.wrappers.FilterObservation)         | Filters a Dict or Tuple observation spaces by a set of keys or indexes.                                                                                                                                                      |
| [`FlattenObservation`](observation_wrappers.md#gymnasium.wrappers.FlattenObservation)       | Flattens the environment’s observation space and each observation from `reset` and `step` functions.                                                                                                                         |
| [`FrameStackObservation`](observation_wrappers.md#gymnasium.wrappers.FrameStackObservation) | Stacks the observations from the last `N` time steps in a rolling manner.                                                                                                                                                    |
| [`GrayscaleObservation`](observation_wrappers.md#gymnasium.wrappers.GrayscaleObservation)   | Converts an image observation computed by `reset` and `step` from RGB to Grayscale.                                                                                                                                          |
| [`HumanRendering`](misc_wrappers.md#gymnasium.wrappers.HumanRendering)                      | Allows human like rendering for environments that support “rgb_array” rendering.                                                                                                                                             |
| [`JaxToNumpy`](misc_wrappers.md#gymnasium.wrappers.JaxToNumpy)                              | Wraps a Jax-based environment such that it can be interacted with NumPy arrays.                                                                                                                                              |
| [`JaxToTorch`](misc_wrappers.md#gymnasium.wrappers.JaxToTorch)                              | Wraps a Jax-based environment so that it can be interacted with PyTorch Tensors.                                                                                                                                             |
| [`MaxAndSkipObservation`](observation_wrappers.md#gymnasium.wrappers.MaxAndSkipObservation) | Skips the N-th frame (observation) and return the max values between the two last observations.                                                                                                                              |
| [`NormalizeObservation`](observation_wrappers.md#gymnasium.wrappers.NormalizeObservation)   | Normalizes observations to be centered at the mean with unit variance.                                                                                                                                                       |
| [`NormalizeReward`](reward_wrappers.md#gymnasium.wrappers.NormalizeReward)                  | Normalizes immediate rewards such that their exponential moving average has an approximately fixed variance.                                                                                                                 |
| [`NumpyToTorch`](misc_wrappers.md#gymnasium.wrappers.NumpyToTorch)                          | Wraps a NumPy-based environment such that it can be interacted with PyTorch Tensors.                                                                                                                                         |
| [`ObstructView`](misc_wrappers.md#gymnasium.wrappers.ObstructView)                          | Randomly obstructs rendering with white noise patches.                                                                                                                                                                       |
| [`OrderEnforcing`](misc_wrappers.md#gymnasium.wrappers.OrderEnforcing)                      | Will produce an error if `step` or `render` is called before `reset`.                                                                                                                                                        |
| [`PassiveEnvChecker`](misc_wrappers.md#gymnasium.wrappers.PassiveEnvChecker)                | A passive wrapper that surrounds the `step`, `reset` and `render` functions to check they follow Gymnasium’s API.                                                                                                            |
| [`RecordEpisodeStatistics`](misc_wrappers.md#gymnasium.wrappers.RecordEpisodeStatistics)    | This wrapper will keep track of cumulative rewards and episode lengths.                                                                                                                                                      |
| [`RecordVideo`](misc_wrappers.md#gymnasium.wrappers.RecordVideo)                            | Records videos of environment episodes using the environment’s render function.                                                                                                                                              |
| [`RenderCollection`](misc_wrappers.md#gymnasium.wrappers.RenderCollection)                  | Collect rendered frames of an environment such `render` returns a `list[RenderedFrame]`.                                                                                                                                     |
| [`RepeatAction`](action_wrappers.md#gymnasium.wrappers.RepeatAction)                        | Repeats the given action for `num_repeats` steps, accumulating the reward.                                                                                                                                                   |
| [`RescaleAction`](action_wrappers.md#gymnasium.wrappers.RescaleAction)                      | Affinely (linearly) rescales a `Box` action space of the environment to within the range of `[min_action, max_action]`.                                                                                                      |
| [`RescaleObservation`](observation_wrappers.md#gymnasium.wrappers.RescaleObservation)       | Affinely (linearly) rescales a `Box` observation space of the environment to within the range of `[min_obs, max_obs]`.                                                                                                       |
| [`ReshapeObservation`](observation_wrappers.md#gymnasium.wrappers.ReshapeObservation)       | Reshapes Array based observations to a specified shape.                                                                                                                                                                      |
| [`ResizeObservation`](observation_wrappers.md#gymnasium.wrappers.ResizeObservation)         | Resizes image observations using OpenCV to a specified shape.                                                                                                                                                                |
| [`StickyAction`](action_wrappers.md#gymnasium.wrappers.StickyAction)                        | Adds a probability that the action is repeated for the same `step` function.                                                                                                                                                 |
| [`TimeAwareObservation`](observation_wrappers.md#gymnasium.wrappers.TimeAwareObservation)   | Augment the observation with the number of time steps taken within an episode.                                                                                                                                               |
| [`TimeLimit`](misc_wrappers.md#gymnasium.wrappers.TimeLimit)                                | Limits the number of steps for an environment through truncating the environment if a maximum number of timesteps is exceeded.                                                                                               |
| [`TransformAction`](action_wrappers.md#gymnasium.wrappers.TransformAction)                  | Applies a function to the `action` before passing the modified value to the environment `step` function.                                                                                                                     |
| [`TransformObservation`](observation_wrappers.md#gymnasium.wrappers.TransformObservation)   | Applies a function to the `observation` received from the environment’s [`gymnasium.Env.reset()`](../env.md#gymnasium.Env.reset) and [`gymnasium.Env.step()`](../env.md#gymnasium.Env.step) that is passed back to the user. |
| [`TransformReward`](reward_wrappers.md#gymnasium.wrappers.TransformReward)                  | Applies a function to the `reward` received from the environment’s `step`.                                                                                                                                                   |
